🇧🇩 DeshSubDispatch

Bangladesh's Open Source MCP Server — hybrid sub-agent dispatcher for any coding agent.

MIT License Node ≥22 MCP Compatible Made in Bangladesh
Download Bundle GitHub Repo Live (Fly.io)

Features

🔀 Hybrid Agents

LLM, process, and HTTP agents in one dispatcher.

🧠 Orchestration

Priority queue, DAG workflows, retries, timeouts, cancellation.

🧩 Skills

Ready-made presets: coder, researcher, summarizer, claude-coder.

🌐 Universal

stdio, Streamable HTTP, and legacy SSE transports.

📦 Self-contained

Single bundle file, no node_modules required.

🇧🇩 Open Source

Built by Bangladeshi developers for the world.

🌐 Public MCP Endpoint (No Auth)

Connect from any MCP client — no API key, no signup, no payment required.

{
  "mcpServers": {
    "DeshSubDispatch": {
      "type": "http",
      "url": "https://deshdsp.fly.dev/mcp"
    }
  }
}

Health: https://deshdsp.fly.dev/health

Quick Start

node server.bundle.cjs --http
# or
TRANSPORT=http PORT=3000 node server.bundle.cjs

Connect (stdio)

{
  "mcpServers": {
    "DeshSubDispatch": {
      "command": "node",
      "args": ["/path/to/server.bundle.cjs"]
    }
  }
}
